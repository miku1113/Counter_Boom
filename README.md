About the Project. Counter-Boom is a 2D real-time multiplayer game developed entirely in Unity. The game offers an asymmetric multiplayer experience where players are assigned one of two unique roles: Thief or hostage. Thief, steal the gold and escape successfully. Hostage, escape the building and prevent the thief from succeeding. Multiplayer functionality is powered by Unity Relay, allowing players to host and join games without a dedicated server. Firebase Authentication and Firebase Realtime Database handle user authentication and player data. ## Features. Real-time multiplayer gameplay using Unity Relay, host-client architecture, Firebase authentication, Firebase real-time database. Custom UI and UX. Custom level design. Role-based game mechanics. Real-time player synchronization. Win and lose conditions. Lobby creation and join system. Network session management.
Tech stack. Unity, C Sharp, Unity Relay, Unity Gaming Services, Firebase Authentication, Firebase real-time database, Git and GitHub. ## My Contributions.
